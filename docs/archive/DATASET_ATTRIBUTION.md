### Use in CallCallum

This dataset is used as reference material for:

- Support-quality examples (patterns of ticket completeness, missing fields)
- Failure-mode taxonomy (common weaknesses in helpdesk tickets)
- Derived non-sensitive fixtures (synthetic assessment cases)
- Manager-scored calibration structures (not scores themselves)
- Benchmark distributions (category, priority, resolution time patterns)

### Attribution Statement

This product includes data from the "Help Desk Tickets" dataset (Version 2) by Mohammad Abdellatif, made available under the Creative Commons Attribution 4.0 International License (CC BY 4.0). The dataset was used as reference material for developing quality-assessment taxonomies and synthetic fixtures. No raw data from the original dataset is included in this repository; only derived, non-sensitive patterns and structures are used.

To view a copy of the CC BY 4.0 licence, visit: https://creativecommons.org/licenses/by/4.0/

### Modifications

The original dataset was used to inform failure-mode definitions, example structures, and calibration reference formats. No original rows or records from the dataset are reproduced in this repository. All derived data has been transformed, anonymised, or authored anew based on observed patterns.

## Third-Party Data Principles

1. All external data is used solely as **reference material** — never as authoritative assessment truth.
2. No raw personal data from any dataset is committed to this repository.
3. All derived content is either synthetic or heavily transformed.
4. Attribution is provided for all datasets where required by licence.
5. Datasets with unverified licences are not used until their terms are confirmed.
